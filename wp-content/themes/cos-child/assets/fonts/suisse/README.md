# Suisse Works + Suisse Int'l (licensed fonts go here)

Swiss Typefaces licenses these fonts commercially. Only add files from a web licence held by Caviar of Switzerland, and keep the licence document in this folder.

When all three files below exist, the whole site switches to them automatically. The switch is the "Site typefaces" block at the end of inc/hx-system.php.

| File                        | Face                  | Used for                                   |
|-----------------------------|-----------------------|--------------------------------------------|
| SuisseWorks-Regular.woff2   | Suisse Works 400      | headlines, section titles, product titles  |
| SuisseIntl-Regular.woff2    | Suisse Int'l 400      | body copy, descriptions, prices            |
| SuisseIntl-Medium.woff2     | Suisse Int'l 500      | labels, buttons, product meta              |

Until then (since 4 Nov 2026) the site uses the free pair: Source Serif 4 (headings, 300–400) and Inter (text, 400–500).

If Suisse Works shows larger or smaller than Source Serif 4 on screen, adjust the sizes in the last blocks of assets/css/hx/typeset.css (homepage) and typeset-site.css (other pages).
