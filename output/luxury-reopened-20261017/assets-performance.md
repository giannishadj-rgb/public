## Limits and evidence

These are real-time simulated mobile browser measurements against Local WP on the same computer. Browser caches were cold; Local WP PHP/opcache, OS file cache and server process may already have been warm. The loopback origin has no production DNS/TLS/CDN path and carries a local noindex header. CPU slowdown is relative to this workstation. This is neither production Core Web Vitals nor a field measurement or production performance guarantee. Repeat on the real hosted origin after deployment; physical iPhone Safari is outside this test.
